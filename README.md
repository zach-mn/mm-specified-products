# M&M Specified Products

Website for **M&M Specified Products LLC** of Woodbury, MN, a consulting and specification-driven
company serving the underground utility industry.

**Live site:** https://zachmn.com/mm-specified-products/

## Development

This is a plain static site: `index.html`, `styles.css` and `script.js`, with no build step.

```bash
python -m http.server
# then open http://localhost:8000
```

GitHub Pages serves the `master` branch, so anything pushed there goes live. Do drafts on a branch.

See [`CLAUDE.md`](CLAUDE.md) for structure, conventions and hosting details.
